Xerji

Xerji is a personal expense tracker for Android and Windows. It records daily expenses, budgets, debts, installments, rent and savings.

All data is stored on the user's own devices. If the user enables sync, the data is also stored in a hidden app folder in the user's own Google Drive so the phone and computer stay in sync.
